01 / PROJECT

Why ToolTruth?

External tools can return information that is valid in isolation but inconsistent with the agent's current state. ToolTruth makes those contradictions explicit before execution.

⌁

Typed consistency

Represent tool outputs and expected state as structured, checkable facts rather than opaque text.

TYPE SAFETY
◌

Staleness detection

Identify information whose freshness no longer satisfies the constraints of an agent action.

FRESHNESS
✓

Illegal-state guards

Stop contradictory or impossible transitions from reaching downstream tools and actions.

02 / SYSTEM

Verification architecture

A deliberately small boundary layer: receive intent, call the external tool, validate the result, then either permit or block the action.
