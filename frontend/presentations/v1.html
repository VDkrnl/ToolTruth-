01 / SCOPE

Project scope & objectives

ToolTruth introduces a verification boundary between an AI agent and external tools. Its purpose is to detect contradictions, stale values, invalid transitions, and other illegal states before a tool result is trusted by the agent.

Core propositionDon't let a plausible tool response become an unverified action.
  • Model tool contracts and relevant state as typed data.
  • Validate tool outputs against expected schemas and state constraints.
  • Expose explainable verification results to the calling agent.
  • Keep a versioned trail of project deliverables and planning decisions.

05 / QUALITY

Performance, security & quality goals

Performance

Static first load should remain lightweight. API responses should be JSON and cacheable where appropriate.

Security

JWT admin authentication, bcrypt password hashes, CORS allow-list, S3 private objects and short-lived pre-signed URLs.

Reliability

Immutable published history, health endpoint, systemd restart policy and explicit error states.

Usability

Responsive public site, accessible navigation, clear upload states and useful feedback.

Maintainability

Separated routers, models, schemas, storage, frontend API client and design tokens.

Observability

Structured application logs and upload/publish records provide an audit trail.
